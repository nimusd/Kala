Clarinet Documentation

Overview

The Clarinet container is an extended conical-bore physical model of a reed instrument. It is built on the Saxofony waveguide algorithm (Perry R. Cook / STK) and adds a vocal-tract formant filter, jaw-aperture vibrato, growl AM, an attack chiff burst, and a configurable nonlinear allpass section inside the feedback loop. The result covers a wide expressive range — from a woody clarinet-like tone to a more assertive saxophone-like character — depending on how blowPosition and the vocal tract are set.

Unlike the Reed container (which models a simpler version of the same algorithm), Clarinet exposes the full parameter surface: the vocal tract output formant, an authentic jaw-aperture vibrato path, a growl AM modulator, a transient chiff and overpressure spike at note onset, and adjustable reed saturation. For a pure cylindrical-bore clarinet timbre, pair the Clarinet container with a Harmonic Generator using an odd-only DNA spectrum and blend the two in a Signal Mixer.

Parameters

Core Reed

Parameter Type Default Range Description
breathPressure Float 0.72 0–1 Static air pressure applied to the reed. Higher values produce a louder, more driven tone. Full physical excitation from sample 1 (no internal breath envelope).
reedStiffness Float 0.45 0–1 Slope of the reed valve function. Higher values make the reed harder to open — brighter, more cutting tone.
reedAperture Float 0.52 0–1 DC offset of the reed opening. Sets the resting aperture of the reed before pressure is applied.
blowPosition Float 0.45 0–1 Position of the bore split point. Counterintuitive: low values (0.05–0.20) produce a saxophone-like tone with a full harmonic series; high values (0.40–0.50) produce a clarinet-like tone with odd harmonics dominant. Default 0.45 gives clarinet character.
noiseGain Float 0.12 0–0.4 Level of white noise injected into the bore. Adds breath texture and airiness.
bellReflection Float 0.85 0.5–0.99 Reflection coefficient at the bell end of the bore. Higher values give more resonance and sustain; lower values produce a duller, more open tone.
reedSaturation Float 0.6 0–1 Reed-opening limiter (clamp on negative reed coefficient). With the correct negative-slope reed model, the reed can open fully; reedSaturation limits how far it opens. Higher values add odd-harmonic content and tighten the tone.

Vocal Tract

Parameter Type Default Range Description
vocalTractFreq Float 700 200–3000 Hz Centre frequency of the vocal tract RBJ bandpass filter applied to the output. Approximate vowel positions: ~500 Hz = “oh”, ~700 Hz = “ah”, ~1200 Hz = “ee”.
vocalTractQ Float 2.5 0.5–10 Q (resonance) of the vocal tract filter. Low Q = broad, gentle colouring; high Q = pronounced resonant peak.
vocalTractGain Float 0.35 0–1 Mix level of the vocal tract filter. 0 = no vocal colouring; ~0.35 = warm, subtle; ~0.8 = strongly vocal. Applied as a post-process output formant (not a feedback path).

Vibrato

Parameter Type Default Range Description
vibratoFreq Float 5.5 0–12 Hz Vibrato oscillator rate.

jawVibratoBlend Float 0.7 0–1 Selects the vibrato mechanism. 0 = pure breath pressure tremolo (volume modulation); 1 = pure jaw aperture modulation (pitch modulation, physically authentic). Blend values mix both paths.

Growl

Parameter Type Default Range Description

growlDepth Float 0.0 0–0.5 AM depth of the growl modulator applied to breath pressure. 0 = off; ~0.1 = subtle rasp; ~0.3 = noticeable growl; ~0.45 = intense, distorted character.

Attack

Parameter Type Default Range Description
attackChiffGain Float 5.0 0–10 Amplitude of the noise burst injected at note onset. Produces the initial chiff or consonant of a real reed attack. 0 removes it entirely for a smooth onset.
attackOverpressure Float 0.4 0–1 Additional breath pressure spike added for the first few milliseconds of each note. Simulates the initial tongue/diaphragm attack of a player and helps the bore jump into oscillation quickly.

Nonlinear Allpass Section

When nlAmount > 0, a first-order nonlinear allpass filter is applied inside the waveguide feedback loop (before the OneZero reflection filter) on every sample. Because it sits inside the loop, harmonic content accumulates with each reflection round-trip rather than acting as a simple post-process. The allpass coefficient θ is derived from a modulation source scaled by nlAmount and clamped to (−0.999, 0.999) for stability.

Type Source Character
0 Open-end signal Signal-dependent modulation. Thickens tone and adds harmonic richness that tracks the bore vibration. The most natural-sounding type for reed timbres.
1 Leaky average of open-end signal Slow, DC-like drift of the coefficient. Produces a gentle tonal shift over time rather than per-sample modulation.
2 Open-end signal² Always positive; responds to energy bursts in the bore. Asymmetric modulation that emphasises the attack and forte moments.
3 Sine wave at nlFreqMod Hz Periodic, independent tremolo-like modulation. At low nlFreqMod values produces slow tonal wobble; at higher values adds audible sidebands.
4 Sine wave at pitch Hz Sine locked to the fundamental frequency. Pitch-coherent waveshaping that maintains consistent timbre across the register.
Parameter Type Default Range Description
nlType Int 0 0–4 Modulation source for the allpass coefficient (see table above)
nlAmount Float 0.22 0–1 Depth of nonlinear filtering. 0 = bypassed; 0.05–0.15 = subtle enrichment; 0.20–0.40 = clear tonal thickening; >0.6 = aggressive/experimental.
nlFreqMod Float 10.0 0–200 Hz Oscillator frequency for NL type 3 only. Ignored by types 0, 1, 2, and 4.

How It Works

Conical Bore Waveguide

The Clarinet container implements a conical-bore waveguide (the Saxofony algorithm). Two coupled delay lines — delay0 (open end, length proportional to 1−blowPosition) and delay1 (bell end, length proportional to blowPosition) — represent the travelling wave in each half of the bore. On every sample:

  1. Reed table: Computes a reed coefficient from breathPressure + delay1_output through a linear valve function with a negative slope: slope = −(0.1 + 0.4 × reedStiffness). The negative slope is critical — it ensures high bore pressure closes the reed (as in a real instrument). The coefficient is clamped by reedSaturation to limit fully-open reed excursions.
  2. Bore junction: The delay lines couple at the blow position. The excitation signal fed into the junction is reedCoeff × pressureDiff + delay1_output, following the STK junction formula.
  3. OneZero filter: A one-zero FIR low-pass y[n] = 0.5 × (x[n] + x[n−1]) applied at the open end, modelling the low-frequency reflection characteristic of the bore.
  4. Nonlinear allpass (optional): Inserted after the OneZero filter and before it feeds back into the delay line, adding harmonic richness on every round trip.
  5. Vocal tract formant: A RBJ bandpass filter centred at vocalTractFreq with Q = vocalTractQ is applied to the output signal (not inside the feedback loop). The filtered signal is mixed with the dry bore output at vocalTractGain.
  6. Growl AM: An AM oscillator at growlFreq Hz modulates the breath pressure by growlDepth, adding periodic amplitude variation that simulates a growl technique.
  7. Vibrato: A sine oscillator at vibratoFreq Hz produces pitch and/or amplitude modulation. jawVibratoBlend = 0 routes it entirely into breath pressure (tremolo); jawVibratoBlend = 1 routes it into the reed aperture (jaw modulation, authentic saxophone technique).
  8. Attack burst: On the first sample of each (non-legato) note, a noise burst scaled by attackChiffGain is injected into the bore, and breathPressure is temporarily boosted by attackOverpressure for a brief onset spike.

Blow Position and Harmonic Content

The blowPosition parameter controls the split between the two delay lines and has a counterintuitive effect on timbre:

  • 0.05–0.20: The bore splits close to the reed end. The short delay1 and long delay0 produce a tone with a full harmonic series — saxophone-like, bright, and even harmonics present.
  • 0.40–0.50: The bore splits at the centre. The delay ratio emphasises odd harmonics and suppresses even ones — clarinet-like, hollow, with characteristic register breaks. This is the clarinet default (0.45).

For a pure clarinet tone, combine blowPosition = 0.45 with a Harmonic Generator using an odd-only DNA spectrum (gainB dominant at 1.0) and blend the two with a Signal Mixer. The HG carries the pitch and spectral identity; the Clarinet contributes breath noise, attack transient, and expressive modulation.

Legato Behaviour

For legato note transitions the bore delay buffers, OneZero filter state, and nonlinear allpass memory are all preserved. The bore continues oscillating at the previous pitch; only the delay lengths are updated. The attack burst is skipped, producing a smooth slur with no re-onset transient. Vibrato phase is also preserved.

For non-legato notes, all bore state is cleared and the attack burst fires normally.

Tail Behaviour

The Clarinet container has its own built-in tail mode. When a note ends, the bore delay buffers drain naturally as breath pressure ramps to zero. This typically takes less than 100 ms. The audio engine detects silence and closes the tail cleanly. A separate Note Tail container is generally not needed unless you want a longer decay or let-ring effect beyond the natural bore drain.

Troubleshooting

No Sound / Very Weak Tone

  1. Ensure breathPressure is above ~0.50. Values below this may not sustain oscillation.
  2. Check that reedAperture is not set to 0.0 (fully closed reed).
  3. If attackOverpressure = 0 and attackChiffGain = 0, the bore must self-start from internal noise — raise noiseGain slightly (to ~0.10) to ensure excitation.

Instrument Plays an Octave Too High

This is a register-jump symptom common with conical-bore models at high breath pressure. Reduce breathPressure (try 0.65) and reedStiffness (try 0.40). Alternatively, increase reedAperture slightly to let more air through at lower pressure.

Click or Pop at Note Start

  1. Reduce attackChiffGain — a value of 2.0–3.0 is more subtle.
  2. Reduce attackOverpressure.
  3. If using a nonlinear allpass, increase nlAttack to give the bore time to stabilise before the effect activates.

Even Harmonics Present / Not Clarinet-Like

Ensure blowPosition is in the 0.40–0.50 range. Lower values (saxophone mode) allow even harmonics. Also confirm the paired Harmonic Generator is using an odd-only DNA spectrum with gainB dominant.

Vibrato Causes Pitch Instability or Silence

Do not connect an LFO directly to pitchMultiplier — the LFO is bipolar and drives the multiplier negative, which collapses the bore. Use the Drift Engine for gentle pitch shimmer, or connect the LFO to vibratoGain to shape vibrato depth instead.
