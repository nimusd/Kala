Pan Documentation

Overview

The Pan container is a stereo pan position controller that outputs a value from -1.0 (full left) through 0.0 (center) to +1.0 (full right). It determines where each note sits in the stereo field.

On its own, it sets a static pan position for all notes in the track. When driven by a Frequency Mapper connected to its controlIn port, it distributes notes across the stereo field based on pitch — low notes to the left, high notes to the right, like a piano keyboard.

Category

Modifiers (Green) — Generates stereo positioning from control signals

Core Concept

pan position = clamp(basePan + controlIn, -1.0, +1.0)

The base pan parameter sets a default position. If a control signal is connected to controlIn (typically from a Frequency Mapper), it is added to the base pan value. The result is clamped to the [-1, +1] range.

Pan is applied per-sample during rendering, so it tracks pitch changes within a note (glissando, vibrato) in real time. Because pan is applied at mix time (not during synthesis), changing the pan value does not require re-rendering notes.

Ports

Input Ports

Port Data Type Default Description
controlIn Control 0.0 External pan control value. Added to the base pan parameter.

Output Ports

Port Data Type Description
panOut Control Final pan position, clamped to [-1.0, +1.0]

Parameters

Parameter Range Default Description
pan -1.0 to +1.0 0.0 Base pan position. -1.0 = full left, 0.0 = center, +1.0 = full right.

How Stereo Panning Works

Pan uses a linear pan law:

leftGain  = min(1.0, 1.0 - panValue)
rightGain = min(1.0, 1.0 + panValue)
  • At pan = -1.0: left = 1.0, right = 0.0 (full left)
  • At pan = 0.0: left = 1.0, right = 1.0 (center)
  • At pan = +1.0: left = 0.0, right = 1.0 (full right)

This is the same pan law used for track-level panning. Per-note pan from the Pan container is applied first, then track-level pan is applied on top.

Typical Usage

Piano-style register panning

Connect a Frequency Mapper to spread notes across the stereo field by pitch:

Frequency Mapper (outputMin=-1.0, outputMax=1.0, curve=Logarithmic)
    controlOut → controlIn → Pan (pan=0.0)

Low notes pan left, high notes pan right. Use the Frequency Mapper's lowFreq/highFreq to control the pitch range, and its curve type to shape the distribution.

Static offset

Set pan to a fixed value (e.g. 0.3) with no connection to controlIn. All notes in the track will be panned slightly right.

Narrow stereo spread

Use a Frequency Mapper with a narrow output range (e.g. -0.3 to +0.3) for subtle stereo width without hard panning.

Interaction with Track-Level Pan

The Pan container provides per-note stereo positioning within a track. The track-level pan knob (in the track mixer) applies on top of the per-note pan. For example, if a note is panned to -0.5 (left) by the Pan container and the track pan is set to +0.3 (right), the final stereo position reflects both.

Notes

  • Only one Pan container per sounit graph is supported. If multiple are present, the last one in execution order is used.
  • Pan values are stored per-sample alongside the rendered audio. This means pan tracks pitch changes smoothly (e.g. during glissando or vibrato).
  • Without a Pan container in the graph, all notes render as center-panned (mono), and only track-level pan applies.
